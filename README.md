# Property Readiness Scoring Framework (PRSF)

### A Data-Driven Framework for Luxury Villa Acquisition at StayVista

The **Property Readiness Scoring Framework (PRSF)** is a data-driven approach developed during my Summer Internship at **StayVista (Vista Rooms Pvt. Ltd.)** to evaluate the readiness of luxury villas for acquisition and onboarding.

The framework transforms a detailed **101-point property checklist** into a structured **25-parameter scoring model**, organized across **5 key readiness dimensions**, and produces a single composite readiness score to support more consistent acquisition decisions.

---

## 🎯 Project Objective

The existing property evaluation process captured extensive operational details but lacked:

- A composite readiness score
- Differentiated, evidence-based weighting
- A standardized readiness classification
- A structured mechanism for identifying critical gaps

The PRSF was developed to bridge this decision gap by converting property-level audit observations into a **standardized, measurable readiness score**.
